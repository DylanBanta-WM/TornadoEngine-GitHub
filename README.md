# Tornado Engine GitHub

A [Tornado Engine](https://github.com/DylanBanta-WM/TornadoEngineCore) module: connect a GitHub account, and publish modules made in `web/modules` (for example by Chat) as:

- **Private**: on GitHub only.
- **Public**: on GitHub, with the topic `tornado-engine-module`.
- **Public with Packagist**: also on Packagist, so other districts can install it from their Modules page.

Connect GitHub and add your Packagist username and API token in Administration → GitHub. Publish from a local module's Publish button on /modules, or ask Chat.
